BISP ANDROID APP - SINGLE PHONE EDITION

Included:
- Unlimited appointments per survey working day (no daily 65-person limit).
- Survey days Monday-Friday.
- Automatically suggests the next weekday for the appointment; date can be changed.
- Unique token, QR slip, search, appointment register, Excel/CSV export and JSON backup/restore.
- Offline app-shell caching after first successful online visit on the same phone/browser.
- Records are stored locally on this phone/browser only.

INSTALL ON ANDROID:
1. Extract this ZIP on a computer.
2. Upload all files (keep the files together) to a free HTTPS static host such as GitHub Pages.
3. Open the generated HTTPS website in Google Chrome on your Android phone while online.
4. Wait until the page loads fully once.
5. Chrome menu (three dots) > Install app / Add to Home screen > Install.
6. Launch BISP from the phone's home screen.
7. Test offline mode after installation and after loading the app online once.

IMPORTANT:
- This is a Progressive Web App, not a standalone APK. HTTPS hosting is required for installation and service-worker offline support.
- GitHub Pages is free for public repositories; your app files hosted there are publicly accessible. Do not publish real CNIC/beneficiary data in the app code or public files.
- Records remain in this phone's browser storage. Clearing browser data, uninstalling or resetting the phone can erase records. Download JSON backups regularly and store them safely.
- QR and Excel libraries need a successful online load once to be cached for offline use.
- This is an independent token prototype, not an official BISP app or official system integration.
